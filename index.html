X-Ray Spotlight

Маска в виде круга следует за курсором и раскрывает скрытый слой.

    Как использовать и настраивать
  • Радиус круга меняется в CSS clip-path: circle(120px).
  • Внутрь .xray-mask-layer можно встроить любой альтернативный контент.

Ribbon Slider

    Как использовать и настраивать
  • В JS строка percent * 150 задает дальность прокрутки ленты.

Velocity Line Cursor

Живая линия-курсор на Canvas. Гнется при движении и оставляет эластичный след, который плавно растворяется.

    Как использовать и настраивать
  • Длина хвоста регулируется в JS переменной maxHistory.
  • Толщина и цвет линии меняются через ctx.lineWidth и ctx.strokeStyle в функции render.

Film Grain Noise

Expanding Pill Nav

Компактный хэдер в форме пилюли с логотипом, который плавно раскрывается по горизонтали при наведении, показывая скрытые ссылки.

    Как кастомизировать
  • Скорость анимации меняется в переменной --dur в классе .pill-nav.
  • Максимальная ширина раскрытия задается в --w.
  • Цвет фона задается в --bg.
  • Ссылки добавляются автоматически — просто дублируй теги <a class="pill-link"> внутри контейнера .pill-links.

Directional Underline

Линия подчеркивания появляется и скрывается точно с той стороны, откуда курсор наведен на текст.

    Как кастомизировать
  • Толщина и отступ меняются в .dir-link::after (свойства height и bottom).
  • Скрипт автоматически вычисляет точную координату мыши в процентах для смены transform-origin, создавая эффект линии, вырастающей прямо из-под курсора.

Difference Blend

Эффект инверсии через mix-blend-mode: difference, наложенный прямо на текст поверх фотографии. Идеально подстраивается под цвета сложного фона.

    Как кастомизировать
  • В качестве фона используется предоставленное фото IMG_0036_.jpg.
  • Текст должен быть белого цвета (color: #FFF), чтобы инверсия на фоне сработала на 100%.

Smart Custom Cursor

Полностью кастомизируемый курсор с плавным шлейфом. Чувствителен к контексту: при наведении на кнопку он аккуратно сжимается, а при клике пульсирует.

    Как кастомизировать
  • В CSS класс .cc-dot отвечает за сам курсор (можно добавить background-image: url(...) для своей фотки или иконки).
  • В CSS класс .cc-follower отвечает за кольцо шлейфа (меняется цвет границ, прозрачность, толщина).
  • Степень сжатия при ховере меняется в переменной --scale внутри состояний .hover и .click.
