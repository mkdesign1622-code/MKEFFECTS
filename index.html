X-Ray Spotlight

Маска в виде круга следует за курсором и раскрывает скрытый слой.

    Как использовать и настраивать
  • Радиус круга меняется в CSS clip-path: circle(120px).
  • Внутрь .xray-mask-layer можно встроить любой альтернативный контент.
CRAFTSMANSHIP
CRAFTSMANSHIP

Ribbon Slider

Интерактивная лента картинок, скроллящаяся за движением курсора.

    Как использовать и настраивать
  • В JS строка percent * 150 задает дальность прокрутки ленты.

Velocity Line Cursor

Живая линия-курсор на Canvas. Гнется при движении и оставляет эластичный след, который плавно растворяется.

    Как использовать и настраивать
  • Длина хвоста регулируется в JS переменной maxHistory.
  • Толщина и цвет линии меняются через ctx.lineWidth и ctx.strokeStyle в функции render.

Hover Image Reveal

При наведении на строку списка плавно всплывает фотография и тянется за курсором.

    Как использовать и настраивать
  • Картинки прописываются в HTML через атрибут data-img="ссылка".
  • У плашки обязательно должен быть pointer-events: none.

Magnetic CTA

Кнопка плавно притягивается к курсору в зоне контейнера.

    Как использовать и настраивать
  • Множитель 0.4 в JS отвечает за силу притяжения.

Text Scramble

Текст хаотично перебирает символы перед тем, как собраться в слово.

    Как настроить
  • В строке chars можно менять набор символов для глитча.
NEURO SYSTEM

Liquid Interface

Формы ведут себя как жидкость, слипаясь друг с другом через SVG-фильтр.

    Как настроить
  • Параметр stdDeviation="10" в SVG задает вязкость.

Invert Block

Стильная инверсия цвета при наведении на блок. Чистый CSS.

    Как настроить
  • Настраивается через смену background и color в состоянии :hover.

Flex Accordion

Горизонтальный аккордеон. Элементы расширяются при наведении, плавно вытесняя соседей.

    Как настроить
  • Используется CSS flex: 1 в базе и flex: 3 при наведении. Первый блок отображается корректно.

Mouse Image Trail

Шлейф из элементов, тянущийся за курсором по экрану.

    Как настроить
  • Дистанция спавна регулируется через проверку Math.hypot.

ТЯНИ КУРСОР

3D Card & Glare

Физичная 3D-карточка с динамическим световым бликом и глубиной слоя.

    Как настроить
  • Угол наклона настраивается через деление смещения мыши / 15 в JS.

Pixel Mosaic

Пиксельная сетка, ячейки которой растворяются при наведении курсора.

    Как настроить
  • Размер сетки задается в CSS Grid repeat(10, 1fr).
